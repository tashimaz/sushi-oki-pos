# ติดตั้งบน vivo Y28

1. โอนไฟล์ APK สำหรับทดลองไปที่โทรศัพท์ แล้วเปิดจากแอปจัดการไฟล์
2. หาก Android ขออนุญาต ให้เปิดสิทธิ์ติดตั้งแอปจากแหล่งนี้สำหรับแอปที่ใช้เปิด APK เมื่อติดตั้งเสร็จสามารถปิดสิทธิ์นั้นได้
3. เปิด **SUSHI OKI POS** และตรวจว่าเห็นโต๊ะ 1–8
4. ไปที่ **เมนู** ตรวจชื่อและกำหนดราคาจริงของรายการและทุกขนาดที่จะขาย จากนั้นยกเลิกเครื่องหมาย **รอยืนยันราคา** และบันทึก
5. จับคู่เครื่องพิมพ์ตาม [คู่มือ Bluetooth](bluetooth.md) และพิมพ์ทดสอบก่อนใช้งานกับออเดอร์จริง

หากใช้ ADB ให้เปิดตัวเลือกนักพัฒนาซอฟต์แวร์และ USB debugging บนโทรศัพท์ เชื่อมต่อสาย และยืนยันคำขอจากเครื่องที่ใช้ทดสอบ

```sh
adb devices
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

ไฟล์ทดสอบลงนามด้วย debug key การอัปเดตแอปเดิมต้องใช้ application ID และคีย์ลงนามชุดเดียวกัน หากต้องเปลี่ยนคีย์ให้ส่งออกข้อมูลก่อนติดตั้งใหม่ การถอนแอปจะลบ SQLite ภายในเครื่อง

## ตรวจรับบนโทรศัพท์จริง

- ปิด Wi-Fi และข้อมูลมือถือ เปิดแอปใหม่ เลือกโต๊ะ เพิ่มอาหาร แก้จำนวนและบันทึกหมายเหตุภาษาไทย
- ใช้ Android บังคับหยุดแอปหรือรีสตาร์ตโทรศัพท์ เปิดกลับมาและตรวจรายการที่บันทึกแล้ว สถานะโต๊ะ และคิว
- ส่งครัวและตรวจใบครัวกับใบบัญชี เพิ่มรายการแล้วตรวจว่าใบครัวรอบถัดไปมีเฉพาะส่วนที่เปลี่ยน ย้ายโต๊ะหลังส่งครัวและตรวจใบแจ้งย้าย
- ปิด Bluetooth ก่อนส่ง ทดสอบเปิดกลับและส่งงานเดิม ทดสอบตัดการเชื่อมต่อระหว่างส่งแล้วตรวจผลจริงก่อนพิมพ์ COPY
- ทดสอบเงินสด ส่วนลด และเงินทอน ทดสอบ QR โดยตรวจรับเงินก่อนติ๊กยืนยัน กดปุ่มจ่ายซ้ำและตรวจว่ามีเพียงหนึ่งบิล
- ส่งออก CSV และสำรอง JSON ผ่านตัวเลือกไฟล์ของ Android ใช้ข้อมูลทดลองเพื่อตรวจการกู้คืนและเปิดแอปซ้ำ
