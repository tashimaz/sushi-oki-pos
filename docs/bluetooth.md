# เชื่อมต่อเครื่องพิมพ์ Bluetooth

รองรับเครื่องพิมพ์ที่ใช้ Bluetooth Classic SPP/RFCOMM และคำสั่ง ESC/POS Raster เครื่องพิมพ์ BLE-only และเครื่องที่ต้องใช้ SDK เฉพาะรุ่นต้องใช้ไดรเวอร์อีกแบบ

1. เปิดเครื่องพิมพ์และใส่กระดาษ เปิดแอปที่หน้า **พิมพ์** แล้วกด **เปิดการจับคู่ Android**
2. ค้นหาและจับคู่ใน Android Settings ใช้ PIN ตามคู่มือเครื่องพิมพ์
3. กลับมาที่แอป กด **ค้นหาอุปกรณ์ที่จับคู่** และอนุญาตสิทธิ์ **อุปกรณ์ใกล้เคียง**
4. เลือกเครื่องพิมพ์ ทดสอบการเชื่อมต่อ เลือก 58 หรือ 80 มม. และกด **บันทึกการตั้งค่า**
5. กด **พิมพ์ทดสอบ** ตรวจความคมชัด ขอบกระดาษ และข้อความภาษาไทยจากใบจริง

แอปวาดใบพิมพ์เป็นภาพด้วยฟอนต์ Noto Sans Thai ที่ติดตั้งมากับแอป ขนาด 58 มม. ใช้ 384 จุด และ 80 มม. ใช้ 576 จุด ตรวจความกว้างพิมพ์จริงกับสเปกเครื่องด้วย

## อ่านสถานะคิว

- **รอส่ง** งานบันทึกใน SQLite แล้ว สามารถกดส่งคิวหลังตั้งค่าเครื่องพิมพ์
- **ยังไม่ได้ส่ง** การเชื่อมต่อหรือการเตรียมภาพล้มเหลวก่อนส่งไบต์ กดลองส่งงานเดิมเมื่อแก้ปัญหาแล้ว
- **ผลไม่แน่นอน** การเชื่อมต่อขาดระหว่างส่ง แอปถูกปิดระหว่างส่ง หรือกู้คืนงานค้างจากไฟล์สำรอง ตรวจใบจริงก่อนกด **พิมพ์ COPY**
- **ส่งข้อมูลแล้ว · รอตรวจใบพิมพ์** Android เขียนข้อมูลลง Bluetooth socket แล้ว การยืนยันว่ากระดาษออกและครบทั้งใบต้องตรวจที่เครื่อง
- **จำลองการส่งแล้ว** สถานะบนเว็บสำหรับดูตัวอย่างใบพิมพ์

แอปหยุดรอบส่งเมื่อเจอข้อผิดพลาด งานที่ยังไม่ได้ส่งจะค้างตามลำดับจนกดลองส่งงานเดิม งานต้นฉบับที่ส่งข้อมูลไปแล้วหรือมีผลไม่แน่นอนจะพิมพ์ซ้ำผ่านปุ่ม COPY และได้ ID งานใหม่
